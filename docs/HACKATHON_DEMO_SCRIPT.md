# AegisAgent live demo

The recorded demo uses the local production app at /treasury, real Zetaris queries, and Nemotron through Nightshift. The underlying enterprise exports are synthetic. Captions identify the workflow and assessment boundary. No funds move during this recording.

## Record it

Start Zetaris and Nightshift, complete README setup, build the app, and run it on port 3001 with SAMPLE_MODE=false. From app/, install the Playwright browser once with pnpm exec playwright install chromium ffmpeg. Then run node --import tsx scripts/treasury-demo.ts. ffmpeg must be on PATH (or set FFMPEG_PATH).

The recorder uses the actual UI and waits for actual responses. It verifies expected decisions, captures screenshots and browser-evidence.json, and exports submission/AegisAgent-demo.mp4. It does not replace API responses or read stored output files. Caption timing follows the actual run; normal duration is approximately two to three minutes. Watch the final recording and confirm it stays within the required 1–4 minutes before uploading.
